## 導入後の短い確認手順

1. 再起動後、`PLaMo Prompt Translator` が検索でき、原文・翻訳先・訳文と操作ボタンが表示されることを確認します。
2. 接続設定でモデル一覧を更新し、使うPLaMoモデルを選択して保存します。
3. `赤いコートの女性が、雨の街を歩いている。` を `en` へ翻訳し、訳文が表示されることを確認します。
4. 訳文を編集して既存の画像生成workflowのテキスト入力へ接続し、Queueします。原文を変えた後は再翻訳または明示採用が必要になることも確認します。
5. workflowを保存・再読込し、訳文が復元されることを確認します。モデルを解放した後も、保存済みの採用済み訳文でQueueできることを確認します。

`examples/translator-node.json` は翻訳ノードだけの例です。画像生成の出力ノードは含まないため、この例だけをQueueして画像が出ることは期待しないでください。

## 自動テストの再実行

パッケージのルートで、ComfyUIが使っているPythonまたはaiohttpの入った開発環境を指定します。

```text
python -m unittest discover -s tests -p "test_*.py" -v
node --test tests/test_frontend.mjs
```

Node.jsは開発テスト用です。このカスタムノードをComfyUIで使うためにNode.jsを追加インストールする必要はありません。
